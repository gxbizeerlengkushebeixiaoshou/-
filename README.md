## 服务页FAQ（4问）

**Q1：保鲜库和冷藏库有什么区别？**  
A：保鲜库温度一般在0℃~10℃，适用于果蔬、鲜肉等短期保鲜；冷藏库温度在-18℃左右，适用于食品、药品等中长期冷冻存储。温度越低，能耗越高，造价也相应增加。

**Q2：冷库建造周期大概多久？**  
A：小型冷库（100㎡以下）一般7-15天可完工；中型冷库（100-1000㎡）约15-30天；大型冷链园区（1000㎡以上）根据规模一般1-3个月。具体周期根据项目复杂度和场地条件确定。

**Q3：你们的保温材料是什么？**  
A：我们自主生产高密度PIR聚氨酯保温库板，具有导热系数低、防火性能好、强度高的特点。同时配套生产电动平移冷库门、防撞自由门、装卸货升降平台等核心保温构件，从源头把控品质。

**Q4：冷库耗电量大吗？怎么节能？**  
A：冷库耗电主要取决于保温性能、制冷设备能效和温控系统。我们采用高密度PIR保温板、变频制冷机组、智能温控系统，可比传统冷库节能30%以上。同时提供老旧冷库节能改造服务。
